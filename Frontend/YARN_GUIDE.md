# Yarn Quick Start Guide

## 🧶 **YARN ADICIONADO COM SUCESSO**

### **⚡ Comandos Principais**
```bash
# Instalar dependências
yarn install

# Servidor de desenvolvimento
yarn dev

# Build para produção
yarn build

# Servidor de produção
yarn start

# Verificar código
yarn lint

# Verificar tipos TypeScript
yarn type-check

# Limpar arquivos de build
yarn clean

# Docker build
yarn docker:build

# Docker run
yarn docker:run
```

### **🚀 Scripts Automatizados**
```bash
# Desenvolvimento rápido
./yarn-dev.sh

# Docker completo
./docker-run.sh
```

### **📦 Vantagens do Yarn**
- ✅ **Mais rápido** que npm
- ✅ **Lockfile mais estável** (yarn.lock)
- ✅ **Better caching** de dependências
- ✅ **Offline mode** quando possível
- ✅ **Workspace support** nativo
