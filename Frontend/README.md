# Frontend - Plataforma MVP de Incubadora de Talentos

Esta aplicação Next.js com App Router oferece uma interface completa para gerenciar programas internos de formação de talentos.

## Tecnologias

- Next.js 14+ com App Router
- Material UI para componentes
- Faker-js para dados mockados
- Recharts para dashboards
- Docker para containerização

## Como executar

### Com NPM:
```bash
npm install
npm run dev
```

### Com Yarn (recomendado):
```bash
yarn install
yarn dev
```

### Para executar com Docker:
```bash
docker build -t talent-incubator .
docker run -p 3000:3000 talent-incubator
```

### Scripts disponíveis:
- `yarn dev` - Servidor de desenvolvimento
- `yarn build` - Build para produção
- `yarn start` - Servidor de produção
- `yarn lint` - Verificação de código
